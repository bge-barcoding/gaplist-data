## Cleaned data files

Files prepared using the [SMaRT pipeline](https://github.com/bge-barcoding/gaplist-data/tree/main/data_cleaning_pipeline)

- Files cleaned with GBIF taxonomic backbone resolution: [gbif_only](https://github.com/bge-barcoding/gaplist-data/tree/main/cleaned_data/gbif_only)
- Files cleaned with Hybrid (Majority Rule + GBIF) taxonomic backbone resolution: [hybrid](https://github.com/bge-barcoding/gaplist-data/tree/main/cleaned_data/hybrid)
- Files cleaned with Majority Rule taxonomic backbone resolution: [majority_rule](https://github.com/bge-barcoding/gaplist-data/tree/main/cleaned_data/majority_rule)
- Files cleaned before taxonomic resolution was enforced: [no_taxonomy_normalization](https://github.com/bge-barcoding/gaplist-data/tree/main/cleaned_data/no_taxonomy_normalization)
