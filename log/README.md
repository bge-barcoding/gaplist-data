## Log files

Files prepared using the [SMaRT pipeline](https://github.com/bge-barcoding/gaplist-data/tree/main/data_cleaning_pipeline)

- Log files cleaned with GBIF taxonomic backbone resolution: [gbif_only](https://github.com/bge-barcoding/gaplist-data/tree/main/log/gbif_only)
- Log files cleaned with Hybrid (Majority Rule + GBIF) taxonomic backbone resolution: [hybrid](https://github.com/bge-barcoding/gaplist-data/tree/main/log/hybrid)
- Log files cleaned with Majority Rule taxonomic backbone resolution: [majority_rule](https://github.com/bge-barcoding/gaplist-data/tree/main/log/majority_rule)
- Log files cleaned before taxonomic resolution was enforced: [no_taxonomy_normalization](https://github.com/bge-barcoding/gaplist-data/tree/main/log/no_taxonomy_normalization)
